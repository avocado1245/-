# 고령자·교통약자를 위한 서울시 대중교통 보행 접근성 및 공간 격차 분석

**서울시 250m 격자(8,566개)·버스정류장(11,362개) 공공데이터와 3D 수치표고(DEM) 보간으로 본 '접근보도 경사 장벽' 및 시간대별 이동 수요 시각화**

한겨레 × 재단법인 숲과나눔 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」(2026) 분석 코드·원자료 처리·시각화 결과 저장소입니다. 3개의 Jupyter Notebook(`.ipynb`)을 통해 지형 경사도, 대중교통 인프라 및 승하차 수요, 고령 생활인구 분포를 입체적으로 분석하고 시각화합니다.

## 바로 재현하기 (Quick Start)

본 저장소의 노트북 코드는 **Google Colab** 및 로컬 Python 환경에서 별도의 세션 재시작 없이 한글 폰트(`NanumGothic`)와 필수 공간분석 패키지를 자동 설치·탐색하도록 설계되어 있습니다.

### 1. 환경 준비 및 패키지 설치
```bash
pip install numpy pandas matplotlib geopandas pyproj scipy shapely
```
* **한글 폰트 자동 설정**: 노트북 상단 공통 준비 블록 실행 시 Linux/Colab 환경에서는 `fonts-nanum`을 자동 설치 및 등록하며, 로컬(Windows/Mac) 환경에서는 `Malgun Gothic`, `AppleGothic`, `Noto Sans CJK KR` 등을 자동 감지하여 적용합니다.
* **스마트 파일 탐색기 (`find_csv`, `find_target_file`)**: Mac/Windows 간 한글 자소 분리(NFD/NFC) 및 공백·언더바(`_`) 차이를 자동으로 정규화하여 `/content`, `./data`, 현재 폴더(`.`) 등에서 원본 CSV와 ZIP 파일을 찾아냅니다.
* **한글 ZIP 인코딩 자동 복원 (`extract_zip_safely`)**: `서울시 경사도.zip` 등 압축 파일 내부의 한글 폴더·파일명(`cp437`/`euc-kr`) 깨짐 현상을 자동 복원하여 압축을 해제합니다.

### 2. 노트북 실행 순서
1. `data/` 폴더(또는 Colab 파일 창)에 원자료 CSV 및 GIS ZIP 파일을 위치시킵니다.
2. 아래 3개의 `.ipynb` 노트북 파일을 순서대로 실행하면 모든 전처리 및 시각화 이미지가 `./output/` 폴더와 화면에 출력됩니다.

## 주요 변수 및 방법론 정의

* **3D 표고 보간 (IDW, 역거리 가중법)**: 수치지도 $1:5,000$ 표고점(`N3P_F002.shp`, $76,580$개) 전체와 등고선(`N3L_F001.shp`, $13,704$개) 정점 샘플링($2,196,650$개)을 결합한 $2,273,230$개 3D 제어점 트리(`cKDTree`)에서 최근접 $k=6$개 지점의 거리의 제곱에 반비례하는 가중치($w_i = 1 / \max(d_i, 0.5)^2$)를 부여하여 임의 좌표의 해발고도($\text{m}$)를 정밀 추정.
* **정류장 접근보도 종단경사도 ($\%$)**: 시내버스 정류장($7,110$개, 가상정류장·선착장·마을버스 제외) 반경 $100\text{m}$ 내 보도 링크의 시·종점 표고 차이를 링크 길이로 나눈 경사율(링크 길이 가중평균)과 국지 지형 경사도(최근접 12개 제어점의 85백분위수~15백분위수 고도차 비율, 단독 실행 시 등가 변환계수 $0.695$ 적용)를 결합하여 산출.
  * **유니버설디자인 기준선**: 경사도 $1/18$ ($5.56\%$) — 휠체어 및 고령 보행자의 자력 이동 안전 기준.
  * **부득이한 경우 최대 기준선**: 경사도 $1/12$ ($8.33\%$) — 「교통약자의 이동편의 증진법」상 보도 종단경사 한계 기준.
* **250m 격자 좌표 디코딩**: 국가지점번호 문자열(예: `다사54254850`)의 한글 초성 매핑(`가~라` $\rightarrow$ 동향 $700,000\sim1,000,000\text{m}$, `가~아` $\rightarrow$ 북향 $1,300,000\sim2,000,000\text{m}$) 및 격자 오프셋($+125.0\text{m}$)을 적용하여 `EPSG:5179` 중심좌표 및 `EPSG:4326` 위경도로 변환.
* **생활인구 비식별(`*`) 보정**: 250m 격자 단위 생활인구 원자료에서 소수 인원 보호를 위해 마스킹된 `*` 기호를 총생활인구 $2.0$명, 65세 이상 연령대별(남·여 65~69세, 70세 이상) $1.5$명으로 보정한 뒤 24시간 평균을 산출하여 공간 누락 방지.

## 한계점

1. **수치표고 보간과 실제 보도 구조물의 차이**: 1:5,000 수치지도 기반 IDW 보간은 지형의 거시적 종단경사를 정밀하게 반영하나, 개별 정류장 앞의 연석 단차(턱), 보도블록 파손, 육교·지하보도 등 미시적 보행 장애물까지는 모두 포착하지 못합니다.
2. **비식별(`*`) 데이터의 상수 대체**: 250m 격자 생활인구의 `*` 마스킹(1~3명 미만)을 일정 상수로 대체하였으므로, 심야 시간대나 외곽 산림 인접 격자에서는 실제보다 고령 인구가 소폭 과대 추정될 가능성이 있습니다.
3. **단면 데이터 한계**: 버스 승하차(2026년 9월)와 생활인구(2026년 10월 특정일)를 기준으로 분석하였으므로, 겨울철 빙판길이나 폭염기 등 계절적 기상 악화 시 고령층의 대중교통 접근성 저하 효과를 시계열로 추적하는 후속 연구가 필요합니다.
