# 서울시 3D 지형·보행 인프라 기반 대중교통 사각지대(ART) 재진단 및 시내버스 정류장 통폐합 3등급 분류

**AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전** 제출용 공식 분석 코드 및 재현 파이프라인 저장소입니다.

## 1. 프로젝트 개요

기존의 2차원(2D) 평면 직선거리 기반 대중교통 접근성 진단은 서울시의 구릉지 지형(경사도), 보행망 우회, 계단 및 횡단보도 등 실제 보행 저항 요인을 반영하지 못해 **'3D 숨은 사각지대'**를 누락하는 한계가 있습니다. 또한 단순 정류장 간격(300m 이내) 및 승하차 인원만을 기준으로 버스정류장을 통폐합할 경우, 급경사 언덕길 고령층의 필수 생명선 정류장이 폐쇄되는 문제가 발생합니다.

본 프로젝트는 **1:5,000 수치지도(표고점 76,580개·등고선 13,704개) 기반 3D IDW 보간 엔진**과 **서울시 250m 격자(8,566개)·시내버스 정류장(7,110개)·시간대별 승하차 빅데이터(2026년 9월)**를 결합하여 다음 과제를 수행합니다.

1. **대중교통 사각지대(ART) 3단계(층 A·B·C) 재진단**: 2D 직선거리(층 A) → 2D 보행망 거리(층 B) → 3D 경사·계단 보정 실효거리(층 C, Tobler 1993) 비교 및 반경 800m 기준 '3D 숨은 사각지대' 발굴
2. **비모수 통계검정 및 민감도 분석**: 3D 숨은 사각지대 vs 접근 가능 지역 간 **Mann-Whitney U 검정**, 경사 보정식 3종(Tobler 1993 / Wood et al. 2023 / Minetti et al. 2002) × 보행속도 6종 시나리오 민감도 분석
3. **시내버스 정류장(7,110개) 통폐합 3등급 분류 및 초기하분포 검정**:
   - **1등급(보존, 5,114개 / 71.93%)**: 급경사(1/18=5.56% 이상) 또는 계단 밀집·배후 고령층 상위 25%·낮 시간대 승하차 집중·정류장 간격 300m 초과 정류장
   - **2등급(통폐합 후보, 779개 / 10.96%)**: 완경사 평지·간격 300m 이내·지하철 200m 역세권 중복·청년층 및 출퇴근 피크 중심 정류장
   - **3등급(현행 유지, 1,217개 / 17.12%)**: 비역세권 완경사 생활권 정류장 (풍선효과 방지)
   - 기존 2D 단순 기준(779개)과의 **초기하분포(Hypergeometric Distribution) 교차 검증** 및 1등급 오분류 침해율 산출
4. **연간 온실가스(CO₂) 감축 잠재량 산출**: 2등급 779개소 통폐합 시 무정차 통과에 따른 연료 절감 및 연간 CO₂ 감축량(보수적 하한·기준·적극적 상한) 산정

## 4. 실행 방법

### 4.1 로컬 환경 실행

1. 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. 원본 데이터 파일(`.csv`, `.zip`)을 프로젝트 루트(`.`) 또는 `./data/` 폴더에 위치시킵니다.
   - 대용량 `서울시 경사도.zip` 파일이 없는 환경에서도 내장된 1:5,000 수치지도 3D 제어점 모델을 통해 에러 없이 전체 파이프라인이 실행됩니다.
3. 파이프라인 실행:
   ```bash
   python master_pipeline.py
   ```
4. 실행 완료 후 `./output/` 폴더에 결과 CSV 2종과 고해상도 시각화 PNG 4종이 자동 저장됩니다.

### 4.2 Google Colab 실행

1. Colab에서 새 노트북을 열고 코드 셀에 `master_pipeline.py` 전체 코드를 붙여넣거나 `%run master_pipeline.py`를 실행합니다.
2. Colab 왼쪽 `[파일(📁)]` 탭에 공모전 원본 CSV 파일들을 업로드한 뒤 실행하면 전 과정 통계 검정표와 시각화 차트가 순서대로 출력됩니다.
